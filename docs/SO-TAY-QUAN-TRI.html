Sổ tay này dành cho người vận hành kỹ thuật. Hướng dẫn nghiệp vụ theo vai trò: xem Hướng dẫn tổng quan.

Bảo mật: Không ghi chuỗi kết nối cơ sở dữ liệu, mật khẩu, khóa bí mật vào tài liệu, tin nhắn hoặc Git. Giá trị thật chỉ nằm trong backend/.env trên máy và trong phần Environment Variables của Vercel.

3.1. Chuẩn bị

  1. Mở PowerShell tại thư mục gốc của repo.
  2. Kiểm tra backend/.env có MONGO_URL và DB_NAME trỏ đúng cơ sở dữ liệu cần nạp. Các script tự đọc file này.
  3. Script đọc GDB cần GDAL: chạy bằng Python của QGIS, C:\Program Files\QGIS 4.0.3\bin\python-qgis.bat.
  4. Script không đọc GDB: chạy bằng Python trong venv của backend, backend\venv\Scripts\python.

3.2. Thửa đất nền địa chính (thay toàn bộ)

Lệnh này xóa hết collection parcels rồi nạp lại.

& "C:\Program Files\QGIS 4.0.3\bin\python-qgis.bat" scripts\import_cadastre_mongo.py "<thư mục dữ liệu>\BD_NenDiaChinh\GeoDatabase\20250808_BanDoNenDiaChinh.gdb" ThuaDat

3.3. Bổ sung thửa nội thị TP. Cao Lãnh

Có --append: giữ thửa đã có, chỉ thêm các phường/xã (MaPhuongXa) chưa nạp. Chạy sau bước 3.2.

& "C:\Program Files\QGIS 4.0.3\bin\python-qgis.bat" scripts\import_cadastre_mongo.py "<thư mục dữ liệu>\QHSDD_tpCaoLanh\GeoDatabase\TPCaoLanh.gdb" ThuaDat_TNMT_DC --append

3.4. Quy hoạch sử dụng đất

Xóa hết planning_zones rồi nạp lại. Lớp mặc định là SuDungDat_TNMT_QH.

& "C:\Program Files\QGIS 4.0.3\bin\python-qgis.bat" scripts\import_planning_zones.py "<thư mục dữ liệu>\QHSDD_tpCaoLanh\GeoDatabase\TPCaoLanh.gdb"

3.5. Giấy phép mẫu

Xóa các giấy phép mẫu cũ (is_demo: true) rồi tạo lại. Mặc định 30 giấy phép; truyền số khác nếu cần.

backend\venv\Scripts\python scripts\seed_demo_permits.py 30
Khi có dữ liệu giấy phép thật: xóa giấy phép mẫu bằng db.permits.deleteMany({is_demo: true}), rồi viết script nạp với các trường permit_no, so_to, so_thua, owner_name, address, issued_date, area_m2, floors.

3.6. Chuyển báo cáo cũ sang hồ sơ vụ việc

Mở hồ sơ cho mọi báo cáo cũ chưa có hồ sơ. Chạy lại nhiều lần vẫn an toàn.

backend\venv\Scripts\python scripts\migrate_reports_to_cases.py

3.7. Kiểm tra sau khi nạp

  1. Mở web quản trị → Bản đồ. Bảng lớp phải ghi đúng tổng số thửa.
  2. Mở một hồ sơ → khối Tiền kiểm online phải hiện thửa đất, quy hoạch, giấy phép.

4. Đợt bay flycam trên máy trạm AI

Hiện trạng: chưa bay đợt nào. Bản online không nhận file ảnh trực giao: file GeoTIFF nặng hàng GB, vượt giới hạn tải lên của Vercel. Ảnh được bổ sung trên máy trạm AI.

sequenceDiagram participant QL as Cán bộ Quản lý participant WO as Web online participant WS as Web trên máy trạm participant API as API cục bộ participant AI as detection-worker participant DB as MongoDB QL->>WO: Đăng ký đợt bay (bổ sung ảnh sau) WO->>DB: Đợt bay "Chờ ảnh" Note over QL,WS: Chép file GeoTIFF vào máy trạm QL->>WS: Bổ sung ảnh ở dòng đợt bay WS->>API: Tải file lên API->>API: Lưu data/cog, chuyển "Chờ AI xử lý" AI->>API: Đọc ảnh, tách mái nhà, đối chiếu thửa AI->>DB: Ghi nghi vấn QL->>WO: Nghi vấn AI: Mở hồ sơ tiền kiểm / Không vi phạm

4.1. Chuẩn bị máy trạm (làm một lần)

  1. Cài Docker Desktop, Node.js, Python.
  2. Lấy mã nguồn từ GitHub.
  3. Đặt mô hình yolo11-seg-buildings.onnx vào services/detection/models/ (xem README trong thư mục đó).
  4. Tạo backend/.env trỏ cùng cơ sở dữ liệu với bản online (MONGO_URL, DB_NAME, JWT_SECRET giống Vercel để đăng nhập dùng chung).
  5. Tạo web/.env với VITE_API_URL=http://localhost:8000.

4.2. Mỗi lần có đợt bay

  1. Trên web online: Đợt bay → Đăng ký đợt bay (bổ sung ảnh sau). Đợt bay ở trạng thái Chờ ảnh.
  2. Chép file GeoTIFF vào máy trạm.
  3. Chạy PostGIS và worker AI. MONGO_URL phải có trong môi trường của lệnh (ví dụ file .env ở thư mục gốc repo): 
    docker compose up -d
  4. Chạy API cục bộ (port 8000), theo HUONG-DAN-CHAY-DU-AN.md mục 5: 
    cd backend
venv\Scripts\uvicorn server:app --host 0.0.0.0 --port 8000
  5. Chạy web quản trị cục bộ: 
    cd web
npm run dev
  6. Mở web cục bộ, đăng nhập Cán bộ Quản lý → Đợt bay → bấm Bổ sung ảnh ở đúng đợt bay → chọn file. API lưu file vào data/cog/; đợt bay chuyển Chờ AI xử lý.
  7. Worker tự nhận việc: Đang chạy AI → Xong (hoặc Lỗi, có ghi lý do). Xem log: docker compose logs -f detection-worker.
  8. Cán bộ Quản lý mở Nghi vấn AI (online hoặc cục bộ), bấm Mở hồ sơ tiền kiểm hoặc Không vi phạm.
Trên web online, nút Bổ sung ảnh chỉ hiện hướng dẫn chép ảnh sang máy trạm. Nút tải file chỉ hoạt động khi web trỏ vào API trên localhost.

6. Chụp lại ảnh cho bộ hướng dẫn

Script docs/capture-screens.mjs chụp toàn bộ ảnh web-*.png và app-*.png trong docs/images/. Script đăng nhập bằng nút demo và đi một hồ sơ qua đủ 16 bước.

Script tạo một hồ sơ demo thật trên bản online, tiêu đề bắt đầu bằng "[Demo hướng dẫn <ngày>]", và đóng hồ sơ đó. Chạy khi được phép thêm dữ liệu demo.
  1. Mở PowerShell ở thư mục gốc repo.
  2. Cài Playwright (một lần): 
    npm i playwright
npx playwright install chromium
  3. Chạy: 
    node docs/capture-screens.mjs
  4. Ảnh ghi đè vào docs/images/. Có thể truyền thư mục khác làm tham số đầu tiên.

Tùy chọn: biến WEB, APP để chụp bản khác bản online; RESUME_CASE=<id> để chụp tiếp một hồ sơ đã tạo từ bước 3.

Ảnh citizen-*.png (văn bản pháp luật, thủ tục, nhà ở xã hội, cá nhân, so sánh AI) là ảnh cũ, giữ lại vì màn hình không đổi.

7. Vận hành hằng ngày và sao lưu

7.1. Kiểm tra hằng ngày

  1. Mở /health, thấy API trả về bình thường.
  2. Đăng nhập web quản trị, xem Tổng quan: số hồ sơ quá hạn, nghi vấn chờ duyệt.
  3. Xem log lỗi trên Vercel nếu người dùng báo lỗi.

7.2. Sao lưu

  • Bật sao lưu định kỳ (snapshot) trên MongoDB Atlas, hoặc dùng mongodump theo lịch.
  • Giữ file GDB nguồn và ảnh GeoTIFF ở ổ lưu trữ riêng. Các script ở mục 3 nạp lại được từ file nguồn.
  • Không commit .env lên Git.

8. Danh sách việc trước khi chạy thật

  • Bỏ nút đăng nhập một chạm (chọn tài khoản demo) ở màn đăng nhập web (web/src/pages/LoginPage.tsx) và app (frontend/app/login.tsx); dùng lại ô email và mật khẩu.
  • Xóa biến RESET_DEMO_ACCOUNTS trên project quyhoach-api, rồi Redeploy.
  • Đổi mật khẩu hoặc xóa 3 tài khoản demo (mục Người dùng trên web quản trị). Tạo tài khoản thật cho Cán bộ Quản lý, Cán bộ Xử lý.
  • Xóa giấy phép mẫu, nạp dữ liệu giấy phép xây dựng thật (mục 3.5).
  • Xóa các hồ sơ demo (tiêu đề "[Demo …]") nếu không cần giữ.
  • Đổi JWT_SECRET sang chuỗi ngẫu nhiên mới (mọi người phải đăng nhập lại).
  • Kiểm tra gói MongoDB Atlas đủ dung lượng: hơn 331 nghìn thửa, 11 nghìn vùng quy hoạch, ảnh hồ sơ và nghi vấn AI tăng theo thời gian.
  • Gắn tên miền riêng cho 3 project Vercel; cập nhật CORS_ORIGINS, VITE_API_URL, EXPO_PUBLIC_BACKEND_URL theo tên miền mới.
  • Bật sao lưu Atlas (mục 7.2).
  • Build bản cài điện thoại bằng EAS (frontend/eas.json) nếu cần phát hành APK hoặc TestFlight.
  • Rà lại lưu ý pháp lý: khung phạt chỉ là gợi ý; người có thẩm quyền quyết định mức phạt.
