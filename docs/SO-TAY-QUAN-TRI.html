2.2. Cơ chế kiểm soát

  • Backend: JWT Bearer; route admin dùng require_admin() (403 nếu không phải admin).
  • Web: AdminRoute chỉ cho role === "admin".
  • Mobile: kiểm tra role; tab admin ẩn khỏi thanh tab.

2.3. Lưu ý — đăng ký admin

Màn đăng ký cho phép chọn Người phụ trách (admin). Trên production cần khóa lựa chọn này trên UI, chỉ tạo admin qua seed/MongoDB, hoặc thêm cổng phê duyệt (chưa có trong code).

3. Quy trình và lưu đồ

3.1. Đăng nhập và phiên JWT

Mục đích: Xác thực và cấp token. Thời hạn JWT: 30 ngày. Token: app qh_token / web qh_web_token.

  1. POST /api/auth/login → bcrypt + JWT.
  2. Client lưu token + user.
  3. Request sau: Authorization: Bearer; GET /api/auth/me khôi phục phiên.
sequenceDiagram participant Client as App_hoac_Web participant API as FastAPI participant DB as MongoDB Client->>API: POST /auth/login API->>DB: Tim user theo email API->>API: bcrypt + JWT 30 ngay API-->>Client: access_token + user Client->>Client: Luu token local Client->>API: GET /auth/me Bearer API-->>Client: UserPublic

3.9. Cập nhật nội dung tra cứu

Không có CMS. Sửa MongoDB (Compass/Atlas) hoặc seed trong backend/server.py (khi collection trống). GPXD: sửa file TypeScript rồi build lại app.

3.10. Sao lưu và phục hồi

4. Vận hành hàng ngày

4.1. Checklist cán bộ quản lý

  1. Đăng nhập web quản trị.
  2. Xem Tổng quan (chờ xử lý / đang xử lý / đã giải quyết).
  3. Xử lý hàng đợi Báo cáo công dân + ghi phản hồi.
  4. Duyệt nghi vấn vi phạm (xác nhận / bác bỏ).
  5. Đối chiếu trên Bản đồ quy hoạch.
  6. (Tùy chọn) Trung tâm Quản trị trên app khi không có máy tính.

4.2. Checklist IT vận hành

  1. API sống bình thường.
  2. Biến môi trường: MONGO_URL, DB_NAME, JWT_SECRET, CORS_ORIGINS.
  3. Frontend/web trỏ đúng URL API.
  4. Sau deploy DB trống: kiểm tra seed users + nội dung.
  5. AI: chỉ bật khi có EMERGENT_LLM_KEY.
  6. Đổi mật khẩu seed; hạn chế tự đăng ký role admin.
  7. Backup MongoDB theo lịch.

6. Phụ lục

6.1. API liên quan quản trị

Auth: POST /auth/register, POST /auth/login, GET /auth/me, PUT /auth/profile, POST /auth/change-password.

Báo cáo: POST /reports, GET /reports/mine, GET /reports (admin), PUT /reports/{id} (admin).

Khác: GET /admin/stats, GET /violations, PATCH /violations/{id}/review, GET /planning/zones, GET /planning/buildings.

6.2. Biến môi trường (tóm tắt)
